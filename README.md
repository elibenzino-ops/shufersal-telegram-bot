# 🛒 בוט טלגרם קבוצתי להשוואת סלים והזמנה מהסופר הזול ביותר (שופרסל + חצי חינם + סופר חביב)

מערכת אוטומטית שמחברת קבוצת טלגרם משפחתית ל-3 רשתות אונליין במקביל — **🔴 שופרסל אונליין**, **🟢 חצי חינם אונליין** ו-**🔵 סופר חביב אונליין**:
משתתפי הקבוצה שולחים הודעות חופשיות בעברית (*"צריך 2 חלב תנובה 3%, קוטג' וחצי קילו עגבניות שרי"*), והמערכת:
1. **מבינה שפה טבעית בעברית (Gemini AI)** – מבדילה בין שיחת חולין לבין בקשת מצרכים, מפרידה מספר פריטים מהודעה אחת, ומזהה כמויות, יחידות/משקל, בקשות הסרה והערות למלקט.
2. **בונה עגלה אמיתית בכל הרשתות במקביל עם התאמת ברקודים** – מחפשת בכל אחת מהחנויות, מתאימה את אותו המוצר (כולל ברקוד זהה כשזמין) וזוכרת ב-SQLite העדפות לכל רשת בנפרד.
3. **משווה מחירים כולל דמי משלוח ומזהה את הסל הזול ביותר 🏆** – בפקודת `/compare` או `/checkout` מדרגת את העגלות מהזולה ליקרה ביותר (כולל הצגת חיסכון, התראה על חוסר פריטים או מינימום הזמנה), ומאפשרת למנהל לסגור הזמנה מהרשת הזולה ביותר!
4. **תומכת ב-2 מצבי הרצה לבחירתך:**
   - **מסלול א' (מומלץ): שרת ענן חינמי 24/7 בישראל (Oracle Cloud Always Free – ירושלים)** – תגובה מיידית תוך שניות לכל הודעה בקבוצה, כפתורי החלפת מוצר/כמות בזמן אמת, השוואת עגלות (`/compare`), בחירת משלוח (`/slots`), טעינת הזמנה פתוחה לעדכון (`/orders`), ואישור סגירת הזמנה מהסופר הזול ביותר (`/checkout`).
   - **מסלול ב': סנכרון דרך GitHub Actions (ללא שרת 24/7)** – טלגרם שומרת בתור את הודעות הקבוצה, ובלחיצת כפתור ב-GitHub (או בתזמון קבוע) רצה משימת סנכרון חד-פעמית (`npm run sync-once`) שמכניסה את כל המצרכים לכל העגלות ושולחת לקבוצה טבלת השוואת מחירים!

## שלב מקדים (משותף לשני המסלולים – 5 דקות)

### 1. יצירת בוט בטלגרם וכיבוי Privacy Mode (חובה!)
1. פתחו שיחה בטלגרם עם [@BotFather](https://t.me/BotFather) ושלחו `/newbot`.
2. בחרו שם ושם משתמש לבוט והעתיקו את ה-**HTTP API Token**.
3. **קריטי לקבוצות:** שלחו ל-`@BotFather` את הפקודה `/setprivacy` -> בחרו את הבוט -> לחצו **`Disable`** *(כדי שהבוט יוכל לקרוא הודעות מצרכים רגילות בקבוצה ולא רק פקודות שמתחילות ב-`/`)*.
4. צרו קבוצת טלגרם למשפחה והוסיפו אליה את הבוט (מומלץ לתת לבוט הרשאת Admin בקבוצה).

### 2. הנפקת מפתח Google Gemini API
היכנסו ל-[Google AI Studio](https://aistudio.google.com/apikey), צרו מפתח API חינמי והעתיקו אותו (`GEMINI_API_KEY`).

### 3. הגדרת חשבונות החנויות (`.env`)
- **🔴 שופרסל אונליין:** הגדירו `SHUFERSAL_USERNAME` ו-`SHUFERSAL_PASSWORD` (עם כתובת וכרטיס שמור ל-`/checkout` אוטומטי).
- **🟢 חצי חינם אונליין (`shop.hazi-hinam.co.il`):** הגדירו `HAZI_HINAM_USERNAME` ו-`HAZI_HINAM_PASSWORD` להתחברות OAuth2 ישירות לחשבון שלכם (אם ריק – עדיין נבנית עגלת השוואת מחירים חיה במצב אורח).
- **🔵 סופר חביב אונליין (`www.superhaviv.co.il`):** הגדירו `SUPER_HAVIV_USERNAME` ו-`SUPER_HAVIV_PASSWORD` (אופציונלי `SUPER_HAVIV_BRANCH_ID=3507`). אם ריק – עדיין נבנית עגלת השוואת מחירים חיה דרך ה-API הציבורי של סופר חביב.
- לשליטה באילו חנויות פעילות: `ENABLED_STORES=shufersal,hazi_hinam,super_haviv`.

## ☁️ מסלול א' (מומלץ): הרצה 24/7 בשרת חינמי בישראל (Oracle Cloud Always Free)

> **למה שרת בישראל?** אתר שופרסל חוסם גישה מכתובות IP של חוות שרתים בחו"ל (ארה"ב/אירופה). ל-Oracle Cloud יש אזור ענן **בישראל (Jerusalem)** עם מכונת לינוקס חינמית לתמיד (**Always Free**).

### 1. יצירת המכונה ב-Oracle Cloud
1. הירשמו/התחברו בכתובת https://www.oracle.com/cloud/free/ ובחרו **Israel Central (Jerusalem)** כ-**Home Region**.
2. עברו ל-**Compute → Instances → Create Instance**:
   - **Image:** בחרו `Canonical Ubuntu 24.04` (או `22.04`).
   - **Shape:** בחרו `VM.Standard.A1.Flex` (עד 4 ליבות ו-24GB RAM בחינם – למשל 2 OCPUs ו-8GB RAM) או `VM.Standard.E2.1.Micro` (1GB RAM בחינם – סקריפט ההתקנה שלנו מוסיף אוטומטית 2GB Swap).
   - **Networking (חשוב):** ודאו שנבחר **Public subnet** ושהאפשרות **Automatically assign public IPv4 address** מסומנת ב-Yes.
   - **SSH Keys:** הורידו את קובץ המפתח הפרטי (`.key`) למחשב ולחצו **Create**.

### 2. התחברות ב-SSH למכונה
- **ב-Windows (פתחו PowerShell):**
  ```powershell
  ssh -i "$HOME\Downloads\ssh-key-XXXX.key" ubuntu@YOUR_PUBLIC_IP
  ```
- **ב-Mac / Linux (פתחו Terminal):**
  ```bash
  chmod 400 ~/Downloads/ssh-key-XXXX.key
  ssh -i ~/Downloads/ssh-key-XXXX.key ubuntu@YOUR_PUBLIC_IP
  ```
*(החליפו את שם קובץ ה-`.key` ואת `YOUR_PUBLIC_IP` בכתובת ה-IP הציבורית מהמסך של Oracle, והקלידו `yes` באישור הראשוני).*

### 3. התקנה והפעלה בפקודה אחת!
בתוך הטרמינל של שרת ה-Oracle, הדביקו:
```bash
git clone https://github.com/elibenzino-ops/shufersal-telegram-bot.git
cd shufersal-telegram-bot
bash scripts/setup-oracle-vm.sh
```
הסקריפט יתקין אוטומטית Docker, יבקש מכם להזין את הטוקן מטלגרם, פרטי שופרסל ומפתח ה-Gemini, וירים את הבוט לריצה קבועה 24/7 (כולל עלייה אוטומטית אחרי ריסטארט).

## 🐙 מסלול ב': הרצה דרך GitHub Actions (ללא שרת 24/7)

אם אינכם רוצים לתחזק מכונה ב-Oracle Cloud ומוכנים לסנכרון תקופתי / לפי לחיצה (ללא כפתורי אינטראקציה חיים 24/7 בצ'אט):
טלגרם שומרת בתור (עד 24 שעות) את כל ההודעות שנשלחו לקבוצה בזמן שהבוט כבוי, והקובץ [`.github/workflows/sync-cart.yml`](./.github/workflows/sync-cart.yml) מושך אותן ומעדכן את עגלת שופרסל.

### שלב 1: פתרון חסימת IP חו"ל של שופרסל (בחרו אחת מ-2 דרכים)
מאחר ששרתי ברירת המחדל של GitHub יושבים בארה"ב ונחסמים ע"י שופרסל:
- **דרך 1 (חינמית ופשוטה): GitHub Self-Hosted Runner על מחשב ביתי בישראל**
  1. בריפוזיטורי שלכם ב-GitHub גשו ל-**Settings → Actions → Runners → New self-hosted runner**.
  2. הריצו את פקודות ההתקנה הקצרות על מחשב ביתי בישראל, והגדירו בריפוזיטורי **Settings → Secrets and variables → Actions → Variables** משתנה בשם `RUNNER_LABEL` עם הערך `self-hosted`.
- **דרך 2: שימוש בשרתי GitHub בענן + פרוקסי ישראלי**
  השאירו ריצה על `ubuntu-latest` והגדירו ב-GitHub Secrets משתנה בשם `PROXY_URL` עם כתובת פרוקסי ישראלי (`http://user:pass@host:port`).

### שלב 2: הגדרת GitHub Secrets
בריפוזיטורי שלכם ב-GitHub, היכנסו ל-**Settings → Secrets and variables → Actions → New repository secret** והוסיפו:
- `TELEGRAM_BOT_TOKEN`
- `SHUFERSAL_USERNAME`
- `SHUFERSAL_PASSWORD`
- `GEMINI_API_KEY`
- `ALLOWED_CHAT_IDS` *(אופציונלי – מזהה הקבוצה השלילי, למשל `-100123456789`)*
- `PROXY_URL` *(רק אם בחרתם בדרך 2 ללא מחשב ישראלי)*

### שלב 3: הפעלת הסנכרון
1. חברי הקבוצה כותבים מצרכים בקבוצת הטלגרם כרגיל לאורך היום/שבוע.
2. כשרוצים למלא את העגלה בשופרסל, נכנסים ללשונית **Actions → Sync Telegram Groceries to Shufersal Cart → Run workflow** (או מפעילים את שורת ה-`schedule` בקובץ ה-workflow לריצה אוטומטית כל 30 דקות).
3. בסיום הריצה תישלח הודעת סיכום מסודרת לקבוצת הטלגרם עם כל המוצרים שנוספו וקישור ישיר לעגלה!
