# 🛒 בוט טלגרם קבוצתי להזמנות אוטומטיות בשופרסל אונליין

מערכת אוטומטית מלאה (24/7 ב-Docker או Node.js) שמחברת קבוצת טלגרם משפחתית/משרדית ישירות לחשבון **שופרסל אונליין**:
משתתפי הקבוצה שולחים הודעות חופשיות בעברית (*"צריך 2 חלב תנובה 3%, קוטג' וחצי קילו עגבניות שרי"*), והבוט:
1. **מבין שפה טבעית בעברית (Gemini AI)** – מבדיל בין שיחת חולין בקבוצה לבין בקשת מצרכים, מפריד מספר פריטים מהודעה אחת, ומזהה כמויות, יחידות/משקל, בקשות הסרה והערות למלקט.
2. **בוחר חכם לפי היסטוריית הקניות והעדפות הבית** – מחפש בחשבון המחובר בשופרסל (שמדרג קודם מוצרים שקניתם בעבר) וזוכר ב-SQLite החלפות שביצעתם בעבר.
3. **מאפשר שליטה בכפתורים לכל פריט** – כפתורי `🔄 החלף מוצר`, `➕`, `➖`, ו-`❌ הסר` ישירות מתחת לכל מצרך שנוסף.
4. **תומך בתהליך מלא עד סגירת הזמנה או עדכון הזמנה קיימת** – בחירת יום ושעת משלוח (`/slots`), טעינת הזמנה פתוחה לעדכון (`/orders`), ואישור סופי מוגן למנהלי הקבוצה בלבד (`/checkout`).

---

## ✨ דרישות מוקדמות קצרות (5 דקות הגדרה)

### 1. יצירת בוט בטלגרם וכיבוי Privacy Mode (חשוב!)
1. פתחו שיחה בטלגרם עם [@BotFather](https://t.me/BotFather) ושלחו `/newbot`.
2. בחרו שם ושם משתמש לבוט והעתיקו את ה-**HTTP API Token** שתקבלו.
3. **קריטי לקבוצות:** שלחו ל-`@BotFather` את הפקודה `/setprivacy`, בחרו את הבוט שלכם, ובחרו **`Disable`**.
   *(ברירת המחדל בטלגרם חוסמת מבוטים לקרוא הודעות רגילות בקבוצה שאינן מתחילות ב-`/`. כיבוי Privacy Mode מאפשר לבוט לראות כשמישהו כותב "תביאו חלב").*
4. צרו קבוצת טלגרם למשתתפים והוסיפו אליה את הבוט (אם כבר הוספתם אותו לפני שינוי `/setprivacy`, הוציאו והכניסו אותו מחדש או הפכו אותו ל-Admin בקבוצה).

### 2. מפתח Google Gemini API
הנפיקו מפתח API חינמי/פעיל ב-[Google AI Studio](https://aistudio.google.com/apikey) והעתיקו אותו עבור `GEMINI_API_KEY`.

### 3. חשבון שופרסל אונליין מוכן להזמנה
וודאו שפעם אחת באתר/אפליקציית שופרסל אונליין:
- מוגדרת **כתובת משלוח ברירת מחדל** בחשבון.
- שמור **כרטיס אשראי ברירת מחדל** (עבור `/checkout` אוטומטי).

## 🚀 הרצה מהירה ב-Docker (מומלץ לריצה קבועה 24/7)

```bash
cd shufersal-telegram-bot

# 1. יצירת קובץ הגדרות
cp .env.example .env
nano .env   # מלאו TELEGRAM_BOT_TOKEN, SHUFERSAL_USERNAME, SHUFERSAL_PASSWORD, GEMINI_API_KEY

# 2. בנייה והפעלה ברקע (עולה אוטומטית גם אחרי הפעלה מחדש של המחשב/שרת)
docker compose up -d --build

# 3. צפייה בלוגים בזמן אמת
docker compose logs -f
```

### נעילת הבוט לקבוצה הפרטית שלכם בלבד (`ALLOWED_CHAT_IDS`)
1. לאחר שהבוט עלה, שלחו בקבוצת הטלגרם שלכם את הפקודה:
   ```text
   /id
   ```
2. הבוט ישיב עם מזהה הקבוצה (למשל `-1001987654321`) ומזהה המשתמש שלכם (למשל `456789123`).
3. הדביקו אותם בקובץ `.env`:
   ```env
   ALLOWED_CHAT_IDS=-1001987654321
   ADMIN_USER_IDS=456789123
   ```
4. הפעילו מחדש:
   ```bash
   docker compose up -d
   ```

## 💻 הרצה מקומית ללא Docker (Node.js 22.5+ / 24+)

ודאו שמותקן במחשב דפדפן Google Chrome או Chromium ו-Node.js מגרסה `22.5` ומעלה:

```bash
npm install
cp .env.example .env
# ערכו את .env
npm run build
npm start
```

לפיתוח ובדיקות:
```bash
npm run typecheck
npm test
```

## 📖 איך עובדים עם הבוט ביומיום?

| פעולה | איך מבצעים בקבוצה |
|---|---|
| **הוספת מצרכים חופשית** | פשוט שולחים הודעה: *"צריך 2 חלב 3%, קוטג', לחם פרוס וחצי קילו מלפפונים"* |
| **הסרת מצרך בשפה חופשית** | *"תורידו את הלחם"* או לחיצה על כפתור `❌ הסר` בכרטיס המוצר |
| **החלפת מותג / גודל** | לוחצים `🔄 החלף מוצר` מתחת להודעת הבוט ובוחרים מוצר חלופי (הבוט ילמד זאת לפעמים הבאות!) |
| **צפייה בעגלה ובסכום** | `/cart` (מציג גם מי ביקש כל מוצר ואם מוצר אזל מהמלאי) |
| **חיפוש ידני בקטלוג** | `/search חלב שיבולת שועל` |
| **בחירת יום ושעת משלוח** | `/slots` – תפריט כפתורים אינטראקטיבי לפי ימים ושעות פנויות |
| **עדכון הזמנה שכבר בוצעה** | `/orders` -> לחיצה על `✏️ טען הזמנה לעדכון` -> הוספת מוצרים בקבוצה -> `/checkout` לשמירת העדכון! |
| **סגירת הזמנה ותשלום** | `/checkout` (**למנהלים בלבד**) – מציג סיכום מלא וכפתור אישור סופי `✅ אשר ובצע הזמנה בשופרסל` |

## 🛡 הערות אבטחה ואמינות
- **תור סנכרון חכם (`AsyncMutex`):** גם אם 5 בני משפחה שולחים הודעות באותה שנייה, כל הפעולות מול עגלת שופרסל מתבצעות בתור מסודר ללא דריסת פריטים.
- **שמירת סשן אוטומטית:** עוגיות ההתחברות נשמרות תחת `./data/shufersal-session.json` לחיבור מהיר ולמניעת התחברויות מיותרות.
- **אימותי בטיחות (OTP / 3D-Secure / CAPTCHA):** המערכת אינה מנסה לעקוף מנגנוני אבטחה או אימות אנושי. אם שופרסל או חברת האשראי ידרשו אימות SMS חד-פעמי או 3D-Secure בקופה, הבוט ישמור את כל העגלה וחלון המשלוח מוכנים וישלח בקבוצה קישור ישיר להשלמה בלחיצה אחת.
